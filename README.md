# Nihal Murarka — Developer Portfolio

## About

A personal portfolio website for Nihal Murarka, a Computer Science & AI student at Scaler School of
Technology who learns by building. The design is calm, minimal and professional: a bento-grid layout
on a soft navy blue palette, with a CSS-only dark/light theme toggle.

## Technologies

- HTML
- CSS

No JavaScript, no frameworks, no build step. The site is `index.html` + `style.css` + `images/`.

## Structure

```
index.html   — all markup (navbar, hero, about, skills, projects, education, contact, footer)
style.css    — the full design system and all animations
images/      — logo.png, profile.jpg, project-1.png
README.md
```

All visible images use standard `<img src="images/...">` tags and are stored locally.
